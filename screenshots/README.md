# Screenshots des projets

Remplacez les fichiers PNG vides par vos captures d'écran.

## Comment faire les screenshots

1. Ouvrez chaque site en local dans votre navigateur
2. Utilisez l'outil de capture intégré (F12 > Ctrl+Shift+P > "Capture full size screenshot")
3. Ou utilisez un outil comme [GoFullPage](https://chrome.google.com/webstore/detail/gofullpage-full-page-scre/fdpohaocaechififmbbbbbknoalclacl)
